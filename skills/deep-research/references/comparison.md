# Comparison

## Method

1. Define the decision and scope (who decides, what workload, what timeframe).
2. Enumerate alternatives: direct, indirect, substitutes, emerging — not just the two named options.
3. Gather quantitative plus qualitative evidence from primary sources for each.
4. Score against pre-declared, decision-relevant criteria applied consistently to all alternatives.
5. Synthesize trade-offs in a matrix, stress-test the conclusion, document limits.

## Matrix rules

- Grade cells as fully, partially, or not supported — never binary yes/no.
- Weight criteria when the decision warrants it; state the weights.
- Ground differentiation in external validation (reviews, analyst reports, trials, production cases), not vendor copy.
- Use consistent definitions and timeframes so rows are comparable.

## Avoid

Feature-list obsession, ignoring substitutes, one-shot analysis with no monitoring plan, confirmation bias, and analysis paralysis. State what would change the recommendation.
